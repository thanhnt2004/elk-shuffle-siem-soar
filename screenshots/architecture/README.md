## Prompt ảnh bìa

Create a wide 3:1 editorial cover image for the GitHub README of a university information security thesis. Dark midnight navy data center environment, subtle realistic 3D rack hardware, three small telemetry streams in blue-cyan converging toward a glass panel and then flowing to one restrained amber alert indicator, technical and understated, high contrast and crisp silhouettes. Add only the literal title 'ELK × SHUFFLE' in a clean legible white sans serif at upper left with ample inset margin, and beneath it only 'SIEM / SOAR LAB'. Keep the text in one uncluttered dark area with all text fully within the horizontal middle band. No other text, icons with brand marks, company logos, watermark, fake dashboard labels or real infrastructure identifiers. This represents defensive centralized log collection and incident response. Professional portfolio asset, restrained color usage, no people.
